# Log Parser

[Log Parser](https://www.npmjs.com/package/@recon-fuzz/log-parser) is a TypeScript utility for parsing and processing logs generated by Medusa and Echidna smart contract fuzzing tools. It extracts structured data from fuzzing logs, including test statistics, execution traces, and broken property details, enabling easier interpretation and integration of fuzzing results into development workflows.

## Used in:
- [Recon - Medusa Tool](https://getrecon.xyz/tools/medusa)
- [Recon - Echidna Tool](https://getrecon.xyz/tools/echidna)

## Installation

```bash
yarn add @recon-fuzz/log-parser
```

## Usage

```typescript
import { processLogs, Fuzzer } from '@recon-fuzz/log-parser';

// Process Medusa logs
const medusaResults = processLogs(medusaLogContent, Fuzzer.MEDUSA);

// Process Echidna logs
const echidnaResults = processLogs(echidnaLogContent, Fuzzer.ECHIDNA);
```

## API Reference

### `processLogs(logs: string, tool: Fuzzer): FuzzingResults`

Parses raw fuzzing logs and returns structured results.

#### Parameters
- `logs: string`: Raw log content as a string.
- `tool: Fuzzer` - One of `Fuzzer.MEDUSA` or `Fuzzer.ECHIDNA`

#### Returns
```typescript
interface FuzzingResults {
  duration: string;
  coverage: number;
  failed: number;
  passed: number;
  results: any[];
  traces: any[];
  brokenProperties: any[];
  numberOfTests: number;
}
```

## Converting to Foundry Tests

Transform Medusa or Echidna logs into reproducible Foundry test cases:

### Echidna

```typescript
import { echidnaLogsToFunctions } from '@recon-fuzz/log-parser';

const foundryTest = echidnaLogsToFunctions(
  echidnaLogs,
  "test_identifier",
  "brokenProperty",
  { roll: true, time: true, prank: true }
);
```

### Medusa

```typescript
import { medusaLogsToFunctions } from '@recon-fuzz/log-parser';

const foundryTest = medusaLogsToFunctions(
  medusaLogs,
  "test_identifier",
  { roll: true, time: true, prank: true }
);
```

The conversion handles:
- VM state manipulation (block numbers, timestamps)
- Sender impersonation (pranks)
- Call sequence reproduction
- Complex input types (addresses, bytes, etc.)

Generated tests will include the exact sequence of calls that triggered the property violation, making it easy to reproduce and debug issues found during fuzzing.
